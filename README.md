> **Important Note on Week Labeling / Mapping:**

| Repository Folder / Tag | Curriculum Schedule | Topic / Focus | Note / Status |
| :--- | :--- | :--- | :--- |

---

## 📝 Reason for Timeline Offset

- **Original Skill Week 1 Requirement:** According to the course guidelines, the initial week focused primarily on environment setup, software installations, and tool configuration, requiring step-by-step screenshots/screen recordings of the setup process.
- **Encountered Constraint:** The setup and installation process was completed without recording real-time screenshots/recordings during the initial setup.
- **Adopted Solution:**
  - **Skill Week 2** content has been mapped and organized under **`Week 1`**.
  - **Skill Week 3** content has been mapped and organized under **`Week 2`**.
  - Subsequent weeks follow this updated numbering sequence to maintain continuous project progression and clear documentation of practical code/assignments.
